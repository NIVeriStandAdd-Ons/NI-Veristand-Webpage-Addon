​​​​​​Overview

This addon publishes NI VeriStand variables to a web page that is hosted on the deployed target.

Repo Location:

https://github.com/NIVeriStandAdd-Ons/NI-Veristand-Webpage-Addon

Requirements

These drivers must be installed on the deployment computer/target to function.

  • NI VeriStand 2026 or later
  • Python 3.14

Initial System Setup

Windows Configuration​

If the desired target is a Windows OS (localhost), first install Python 3.14.

Once done, run this batch file by navigating to it and double clicking.

C:\Users\Public\Documents\National Instruments\NI VeriStand <Year>\Custom Devices\WebPage Addon\Python WebPage\win_create_venv.bat

This will create a python virtual environment (.venv) and install required packages into the venv.

This should only need to be done once for a given Windows machine unless you uninstall NI VeriStand.

NI Linux RT Configuration​

If the desired target is a NI Linux RT OS (cRIO/PXI RT), use sftp (e.g. Filezilla) to move the linux_install_script.sh to the main folder on the target:


Specifically, move:

(Windows) C:\Users\Public\Documents\National Instruments\NI VeriStand <Year>\Custom Devices\WebPage Addon\Python WebPage\linux_install_script.sh

To

(NI Linux RT) /home/admin/linux_install_script.sh

Next, connect via PuTTy to the NI Linux RT target and run the script by typing:

bash linux_install_script.sh

This will install python, create a virtual environment, and install required packages for the webpage.

This will need to be done per NI Linux RT target. It should not need to be done again unless you format the target.

Addon Configuration​

Once the targets are set up, use the addon in VeriStand be right clicking on Custom Devices and select WebPage Addon.

A GUI will ask to either create a new configuration or load a previous:


Initially, select New Instance.

On the main page in VeriStand, update:

-        IP Address (On Windows, use the external IP, NOT localhost, so the webpage will be public)

-        Hosted Port

-        gRPC Port

The IP address and hosted port make up the webpage address. The IP address and gRPC port make up the address to issue a stop command to shutdown the webpage (happens automatically when the VeriStand is undeployed).

Next, right-click on the addon and Select Channels:


This will open a GUI for selecting existing channels to publish via the webpage:

Once done, hit select.

If you need to disable the webpage but want to keep the configuration, right-click on the addon and select Disable.

If you need to transfer the configuration to another VeriStand configuration, right-click on the addon and select Export Configuration.

To use the exported .dat file in a new configuration, re-add the addon and select “Load From File”. Make sure to update IP and port settings for the new target/configuration.

Addon Execution

Deploy the system definition. Type the hosted IP address and hosted port into a web browser like chrome. Format will be:

http:://<Hosted IP>​:<Hosted Port>

The graph will plot all channels. Enable / disable the which channels are visible by clicking on the channel name.

Below the graph will be an individual display per channel that also has an individual plot.
