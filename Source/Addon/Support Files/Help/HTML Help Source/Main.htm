WebPage Addon

MAKE SURE TO DO INITIAL SYSTEM SETUP DOCUMENTED IN THE QUICK START GUIDE.

The quick start document is located at:

"C:\Users\Public\Documents\National Instruments\NI VeriStand (Year)\Custom Devices\WebPage Addon\Windows\Quick Start Documentation\WebPage Addon Quick Start.html"

This addon publishes NI VeriStand variables to a web page that is hosted on the deployed target.

What do you want to do?

Update Settings

Type the desired values into the Hosted IP Address, Hosted Port, and gRPC Port. Check that the created addresses are what is desired.

Select Channels

To select the channels to publish to the webpage, right-click on the add-on and select Select Channels from the shortcut menu. This will open a GUI that allows the user to select existing channels to publish.

Disable Add-on

To disable this add-on, right-click on the add-on instance and select Disable from the shortcut menu.

Export Add-on Configuration

To export this add-on configuration, right-click on the add-on instance and select Export Config from the shortcut menu.
